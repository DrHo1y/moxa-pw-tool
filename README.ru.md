# moxa-pw-tool

Офлайн-утилита для расшифровки и шифрования паролей учётных записей коммутаторов **Moxa ICS-G7852A** и **ICS-G7800A** (прошивка **5.x**, в том числе 5.6, 5.9 и 5.12) — поле `PasswordEncryp`. Алгоритм взят из официальной прошивки. Зависимостей нет — нужен только Python 3.

🇬🇧 English version: [README.md](README.md)

## Что делает инструмент

Поле `PasswordEncryp` в конфигурации коммутатора — это **не хеш**, а обратимое шифрование пароля. Программа:

- расшифровывает 64-символьную hex-строку `PasswordEncryp` обратно в пароль;
- шифрует заданный пароль в тот же формат (`--encrypt`);
- проверяет целостность MD5-хвоста и показывает «хвосты» в 16-байтном буфере, если они есть.

Основной файл — `moxa_ics_password.py` в корне репозитория, запуск на Windows — `run_ics.bat`.

В каталоге `legacy/` лежит более ранняя утилита словарного перебора ключа. Она **не** реализует схему прошивки 5.x и нужна только как историческая справка. Подробности — в `legacy/README.md`.

## Схема шифрования (прошивка 5.x)

Проверено на официальных прошивках ICS-G7852A / линейки ICS-G7800A версий **5.6**, **5.9** и **5.12**. Алгоритм во всех трёх одинаковый.

1. Пароль укладывается в **16-байтовое поле**. Хвостовые пробелы срезаются, остаток добивается нулевыми байтами (`NUL`). Сравнение при входе идёт как с обычной C-строкой — до первого нуля.
2. Поле делится на два блока по 8 байт. Каждый блок шифруется **DES** независимо.
3. Ключ зашит в прошивку как ASCII-строка **`MOXA2DES`** (8 байт). Важно: прошивка копирует эти 8 байт в 128-байтную таблицу ключа **как есть**, без стандартной развёртки ключа DES (key schedule). Остальные 120 байт таблицы — нули. Поэтому обычный DES/3DES из криптобиблиотек этот ключ «не понимает».
4. 16 байт шифртекста записываются строчными hex-цифрами (32 символа). К ним дописывается **MD5 этой hex-строки** (ещё 32 hex-символа). Итого в поле `PasswordEncryp_N=` ровно **64 символа**.

При смене пароля коммутатор не всегда затирает все 16 байт буфера: после завершающего нуля может остаться мусор от более длинного предыдущего пароля. На вход в логин это не влияет, но шифртекст из-за этого может не совпасть с «чистым» шифрованием той же короткой строки.

## Установка и запуск (Windows)

1. Установите [Python 3](https://www.python.org/downloads/). На шаге установки отметьте **Add Python to PATH**.
2. Дополнительные пакеты **не нужны**.
3. Запуск: двойной клик по `run_ics.bat` или в командной строке из папки репозитория:

```bat
py moxa_ics_password.py --help
```

На Linux / macOS то же самое: `python3 moxa_ics_password.py`.

## Примеры

Расшифровать значение из конфигурации (64 hex-символа поля `PasswordEncryp_N=`):

```bat
py moxa_ics_password.py cd280c9b2e88ac8cb11c724eba8d55a8c68e6b6eb9114353c3420dfc71829f66
```

Зашифровать пароль в формат конфигурации:

```bat
py moxa_ics_password.py --encrypt "ExamplePass1"
```

Ожидаемый результат для этого примера:

```
cd280c9b2e88ac8cb11c724eba8d55a8c68e6b6eb9114353c3420dfc71829f66
```

Самопроверка встроенных тестов:

```bat
py moxa_ics_password.py --selftest
```

Без аргументов программа берёт встроенный пример (удобно для быстрой проверки). Для реальной конфигурации всегда передавайте свою hex-строку явно.

## Фон: CVE-2017-13699

В 2017 году для коммутаторов Moxa EDS-G512E была опубликована уязвимость [CVE-2017-13699](https://nvd.nist.gov/vuln/detail/CVE-2017-13699) (также CNVD-2017-37712): пароли в конфигурации хранились с обратимым шифрованием и фиксированным ключом в прошивке, поэтому их можно было восстановить, имея файл конфигурации и зная схему.

Инструмент в этом репозитории относится к другой линейке (ICS-G7800A / ICS-G7852A, прошивка 5.x), но класс проблемы тот же: `PasswordEncryp` — это шифр с ключом, зашитым в `.rom`, а не односторонний хеш. Зная алгоритм и ключ, значение из конфигурации можно расшифровать офлайн.

## Безопасность и этика

Этот код предназначен **только для восстановления доступа к собственному оборудованию** (или к оборудованию, которым вы имеете право администрировать): забытый пароль, разбор собственного файла конфигурации, проверка, как коммутатор сохраняет учётные записи.

Не используйте утилиту против чужих устройств и чужих конфигураций. Поле `PasswordEncryp` обратимо — после восстановления доступа смените пароли и ограничьте, у кого есть копии конфигурации и прошивки.
