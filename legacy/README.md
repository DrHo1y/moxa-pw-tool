# legacy — ранний словарный перебор

Это **не** рабочий расшифровщик для ICS-G7852A / ICS-G7800A с прошивкой 5.x.

Папка содержит первую утилиту (`moxa_decrypt.py`): она пыталась подобрать ключ
прошивки перебором (встроенный словарь, свой `--wordlist`, опционально `--pin`)
в предположении, что это обычный DES / 3DES / Blowfish в режиме CBC с
фиксированным ключом и IV.

Это предположение оказалось неверным. В прошивке 5.x используется нестандартный
DES: строка `MOXA2DES` копируется в таблицу ключа **как есть**, без стандартной
развёртки (key schedule). Библиотечный DES из pycryptodome такой ключ не считает,
поэтому словарный перебор его и не находил.

Для реальной расшифровки и шифрования поля `PasswordEncryp` используйте
`moxa_ics_password.py` в корне репозитория — пакеты для него не нужны.

Если всё же запускаете этот инструмент:

1. Python 3, галочка «Add Python to PATH».
2. `py -m pip install pycryptodome`
3. Двойной клик по `run.bat` или `python moxa_decrypt.py`.

Флаги: `--wordlist keys.txt`, `--pin 4`, `--selftest`, `--extra-ciphers`.
Пример словаря — `wordlist_example.txt`.
